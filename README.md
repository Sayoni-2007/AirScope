
# 🌍 AirScope - India's Air Quality Explorer

## About the Project
AirScope is a Python-based data analysis dashboard that explores air quality across different Indian cities.

It uses Pandas for data analysis and cleaning, and Streamlit for creating an interactive dashboard.

## Features
- Dataset preview
- Dataset information and statistics
- Data cleaning and duplicate removal
- Missing value handling
- City-wise AQI comparison
- AQI trend analysis
- Pollutant level visualisation
- Interactive city and date filters
- Download cleaned dataset

## Technologies Used
- Python
- Pandas
- Streamlit
- Plotly

## Dataset
The project uses a sample CSV dataset containing city names, dates, AQI values and pollutant measurements.

Note: The included dataset is illustrative practice data, not official or live CPCB data.

## How to Run

1. Install the required libraries:

   py -m pip install -r requirements.txt

2. Run the application:

   py -m streamlit run app.py

3. Open the local URL displayed in the terminal.
